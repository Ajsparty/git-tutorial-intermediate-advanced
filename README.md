# Intermediate to Advanced Git Tutorial

Welcome to this clear, practical tutorial on intermediate to advanced Git concepts. This guide is designed for developers who already know the basics (clone, commit, push, pull) and want to master branching strategies, collaboration workflows, and powerful history-rewriting tools.

## What You Will Learn

- Advanced branching and merging strategies
- Rebasing vs merging
- Forking repositories and contributing via pull requests
- Cherry-picking, stashing, and interactive rebase
- Conflict resolution techniques
- Tags, bisect, and other advanced commands
- Best practices for clean history and team collaboration

## Prerequisites

- Basic Git knowledge: `git init`, `git clone`, `git add`, `git commit`, `git push`, `git pull`
- A GitHub account (or similar hosting service)
- Git installed locally (version 2.30+ recommended)

## How to Use This Tutorial

Each section is a self-contained Markdown file in this repository. Work through them in order, or jump to the topic you need. Every lesson includes:

- Clear explanations in plain language
- Exact commands you can copy and run
- Common pitfalls and how to avoid them
- Practical examples
